# barockok/tap

Homebrew casks for [uttero](https://uttero.dev) and other apps by barockok.

```
brew tap barockok/tap
brew install --cask uttero
```

Or in one line: `brew install --cask barockok/tap/uttero`.

uttero updates itself, so `brew upgrade` leaves it alone. The cask is bumped by each uttero release.
