# barockok/tap

Homebrew casks for [uttero](https://uttero.dev).

```
brew install --cask barockok/tap/uttero
```

That taps this repo and trusts the cask (Homebrew 7 asks you to trust third-party taps). After that, `uttero` works as a bare name: `brew info --cask uttero`, `brew uninstall --cask uttero`.

uttero updates itself, so `brew upgrade` leaves it alone. Each uttero release bumps the cask here.
